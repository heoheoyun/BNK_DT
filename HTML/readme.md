# 💻 HTML & CSS 학습 저장소
> **금융DT 아카데미 개발자 양성과정 - 웹 퍼블리싱 기초 실습 공간**

이 저장소는 **Visual Studio Code**를 활용하여 HTML과 CSS의 기초를 학습하고 실습한 코드들을 관리하는 공간입니다.

---

## 🛠️ 개발 환경 (Environment)

* **IDE**: Visual Studio Code
* **Browser**: Chrome / Edge
* **Extensions**: 
  * Live Server
  * Prettier - Code formatter
  * HTML CSS Support

---

## 📂 프로젝트 구조

* 각 폴더는 학습 주제별로 구성되어 있습니다.
* HTML 파일(`.html`)과 CSS 파일(`.css`)로 분리하여 관리합니다.
* 이미지 및 기타 리소스는 `assets` 또는 `images` 폴더에 저장됩니다.

---

## 🚀 VS Code에서 실행 및 확인 방법

1. **프로젝트 열기**:
   * `File` -> `Open Folder...` -> 해당 프로젝트 폴더 선택

2. **Live Server로 실행**:
   * HTML 파일 우클릭 -> `Open with Live Server` 선택
   * 또는 하단 상태바의 **Go Live** 버튼 클릭

3. **결과 확인**:
   * 브라우저가 자동으로 열리며 실시간으로 변경사항 확인 가능
   * 코드 수정 시 자동으로 새로고침됩니다.

---

## 📝 학습 기록 가이드

* 모든 코드는 웹 표준(Web Standards)을 준수하며 작성되었습니다.
* HTML의 시맨틱 구조와 CSS의 레이아웃 기법을 이해하고 구현하는 데 집중하였습니다.
* 반응형 웹 디자인(Responsive Web Design) 원칙을 적용하였습니다.
