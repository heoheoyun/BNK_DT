# Java Object-Oriented Programming (OOP) 심화 실습
> **금융DT 아카데미 d0108 패키지 - 객체 협력 및 데이터 관리 실습**

본 실습은 계산기 연산 로직, 단어 맞추기 게임 알고리즘, 회원 관리 시스템 등을 통해 Java의 객체지향 원칙을 심화 학습하고, 핵심 API인 String 클래스의 활용 능력을 배양하는 것을 목적으로 합니다.

---

## 개발 환경 및 핵심 개념
* **IDE**: Eclipse IDE
* **핵심 개념**: 
    * **메소드 오버로딩(Overloading)**: 동일한 이름의 메소드를 매개변수의 타입이나 개수에 따라 다르게 정의하여 유연한 인터페이스 구축
    * **문자열 조작 API**: String 클래스의 내장 메소드를 활용한 데이터 가공 및 검증
    * **데이터 관리 객체(DAO/Storage)**: 객체 배열을 활용하여 데이터를 저장, 검색, 조회하는 로직 설계
    * **캡슐화(Encapsulation)**: private 접근 제한자와 Getter/Setter를 통한 데이터 보호 및 무결성 유지

## 주요 실습 프로젝트 (d0108)

### 1. Java String 클래스 활용 (EX_String.java)
* **학습 내용**: 문자열 데이터를 효율적으로 처리하기 위한 표준 메소드 실습
* **주요 기능**:
    * **조회**: length() (길이), charAt() (특정 위치 문자 반환), indexOf() (문자열 검색)
    * **변형**: trim() (공백 제거), replace() (문자 치환), toUpperCase() / toLowerCase() (대소문자 변환)
    * **추출**: substring() (부분 문자열 추출), split() (특정 구분자 기준 분할)

### 2. 사칙연산 계산기 시스템 (Calculator.java, Test_Calc.java)
* **요구사항**: 실행 클래스(UI)와 연산 처리 클래스(Calculator)의 역할 분리
* **구현 핵심**: 
    * Calculator 클래스 내 사칙연산 메소드 구현 및 결과값 반환
    * 나누기 연산 시 double 형변환을 통한 정밀도 확보 및 0으로 나누기 예외 상황에 대한 방어적 로직 적용

### 3. 영단어/문장 맞추기 게임 (WordGame.java, Test_Game.java)
* **요구사항**: 5글자 단어 또는 랜덤 문장을 맞추는 알고리즘 구현
* **구현 핵심**: 
    * **4가지 모드**: 완전 랜덤 알파벳, 사용자 직접 설정, 준비된 단어셋, 문장(Sentence) 맞추기 모드 제공
    * **로직 구현**: 정답 배열(word)과 가려진 배열(secretWord)을 비교하여 실시간 진행 상태 관리
    * **검증**: checkAlphabet()으로 유효 문자를 판별하고, 대문자를 소문자로 자동 변환하여 비교 로직의 일관성 유지

### 4. 회원 정보 관리 프로그램 (Member.java, Storage.java, Test_Member.java)
* **요구사항**: 회원 정보(이름, 번호, 성별, 주소) 등록 및 속성별 조회/검색 기능 구현
* **구현 핵심**: 
    * **Storage 관리**: Member 객체 배열을 생성하고 빈 인덱스를 탐색하여 객체를 저장하는 로직 구현
    * **맞춤 검색**: 이름, 전화번호, 성별, 주소 등 각 필드별 검색 기능을 제공하여 데이터 접근성 향상
    * **정적 멤버**: static int count를 활용하여 인스턴스 생성 시마다 등록 회원 수 자동 카운팅
    * **데이터 가공**: 성별 코드('M'/'F')를 사용자 친화적인 문자열("남자"/"여자")로 변환하여 출력 및 toString() 오버라이딩
