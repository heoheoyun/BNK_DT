# ☕ Java Object-Oriented Programming (OOP) 심화 실습
> **금융DT 아카데미 d0108 패키지 - 객체 협력 및 데이터 관리 실습**

이 폴더는 계산기, 단어 맞추기 게임, 회원 관리 시스템 등 실질적인 비즈니스 로직과 Java의 핵심 API인 `String` 클래스 활용법을 학습한 심화 실습 결과물들을 담고 있습니다.

---

## 🛠️ 개발 환경 및 핵심 개념
* **IDE**: Eclipse IDE
* **핵심 개념**: 
  * [cite_start]**메소드 오버로딩(Overloading)**: 동일한 이름의 메소드를 매개변수 타입이나 개수에 따라 다르게 정의하여 유연성 확보 [cite: 1]
  * **문자열 조작 API**: Java `String` 클래스에서 제공하는 다양한 내장 메소드 활용
  * [cite_start]**데이터 관리 객체(DAO/Storage)**: 객체 배열을 활용한 데이터 저장, 검색 및 조회 로직 구현 [cite: 2]
  * **캡슐화(Encapsulation)**: 필드 `private` 선언 및 `Getter/Setter`를 통한 데이터 보호

## 📂 주요 실습 프로젝트 (d0108)

### 1. Java String 클래스 활용 (`EX_String.java`)
* **핵심 내용**: 문자열 데이터를 효율적으로 처리하기 위한 표준 메소드 학습
* **주요 기능**:
  * `length()`: 문자열 길이 반환
  * `charAt()`, `substring()`: 특정 위치 문자 반환 및 부분 문자열 추출
  * `indexOf()`, `lastIndexOf()`: 특정 문자(열)의 위치 검색
  * `trim()`, `replace()`: 공백 제거 및 문자열 치환
  * `toUpperCase()`, `toLowerCase()`: 대소문자 일괄 변환

### 2. 사칙연산 계산기 시스템 (`Calculator.java`, `Test_Calc.java`)
* **요구사항 (`CalcQ.txt`)**: UI 담당 클래스와 연산 처리 클래스의 분리
* **구현 핵심**: 
  * 나누기 연산 시 0으로 나누는 경우에 대한 예외 로직 처리
  * 정수 입력을 `double`로 형변환하여 연산 결과의 정밀도 확보

### 3. 영단어/문장 맞추기 게임 (`WordGame.java`, `Test_Game.java`)
* **요구사항 (`wordgame.txt`)**: 5글자의 영단어 또는 문장을 맞추는 로직 구현
* **구현 핵심**: 
  * [cite_start]**4가지 모드**: 완전 랜덤 알파벳, 사용자 직접 설정, 미리 정의된 단어셋, 문장(Sentence) 맞추기 [cite: 1]
  * [cite_start]**게임 로직**: `char[]` 배열을 활용해 정답을 가리고(`*`), 입력값과 비교하여 정답을 공개하는 메커니즘 [cite: 1]
  * [cite_start]**입력 검증**: 알파벳 여부 확인 및 대문자의 소문자 자동 변환 기능 [cite: 1, 3]

### 4. 회원 정보 관리 프로그램 (`Member.java`, `Storage.java`, `Test_Member.java`)
* **요구사항 (`MemberQ.txt`)**: 회원 정보 등록 및 속성별 조회 기능 구현
* **구현 핵심**: 
  * [cite_start]**Storage 관리**: `Member` 객체 배열을 순회하며 빈 공간을 찾아 저장하는 로직 [cite: 2]
  * [cite_start]**다양한 검색**: 이름, 전화번호, 성별, 주소 등 필드별 맞춤 검색 메소드 제공 [cite: 2]
  * **데이터 변환**: `M`/`F` 문자를 "남자"/"여자" 문자열로 변환하여 사용자 친화적 정보 제공
  * **정적 멤버**: `static int count`를 통해 인스턴스 생성 시마다 회원 수 카운팅

## 🚀 실행 및 테스트 방법
1. Eclipse 워크스페이스에서 `d0108` 패키지를 선택합니다.
2. 각 프로젝트의 메인 실행 파일(`Test_...` 또는 `EX_...`)을 실행합니다.
   * **API 학습**: `EX_String.java`
   * **계산기**: `Test_Calc.java`
   * **단어 게임**: `Test_Game.java`
   * **회원 관리**: `Test_Member.java`
3. 콘솔 인터페이스의 안내에 따라 키보드 입력을 진행하며 결과를 확인합니다.
