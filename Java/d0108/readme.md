> **금융DT 아카데미 d0108 패키지 - 객체 협력 및 데이터 관리 실습**

이 폴더는 계산기, 단어 맞추기 게임, 회원 관리 시스템 등 실질적인 비즈니스 로직과 게임 로직을 Java의 객체지향 원칙(OOP)에 따라 설계하고 구현한 결과물들을 담고 있습니다.

## 🛠️ 개발 환경 및 핵심 개념
* **IDE**: Eclipse IDE
* **핵심 개념**: 
  * [cite_start]**메소드 오버로딩(Overloading)**: 동일한 이름의 메소드를 매개변수 타입이나 개수에 따라 다르게 정의하여 유연성 확보 [cite: 1]
  * [cite_start]**배열과 문자열 처리**: `char[]`와 `String` 간의 변환 및 랜덤 라이브러리(`Random`) 활용 [cite: 1]
  * [cite_start]**데이터 관리 객체(DAO/Storage)**: 객체 배열을 활용한 데이터 저장, 검색 및 조회 로직 구현 [cite: 2]
  * **캡슐화(Encapsulation)**: 필드 `private` 선언 및 `Getter/Setter`를 통한 데이터 보호

## 📂 주요 실습 프로젝트 (d0108)

### 1. 사칙연산 계산기 시스템 (`Calculator.java`, `Test_Calc.java`)
* **요구사항 (`CalcQ.txt`)**: 실행 클래스는 콘솔 UI를 담당하고, `Calculator` 클래스는 실제 연산 처리를 분리하여 수행함.
* **구현 핵심**: 
  * 나누기 연산 시 0으로 나누는 예외 상황을 처리함.
  * 정수 입력을 `double` 타입으로 형변환하여 소수점 결과까지 정확히 도출함.

### 2. 영단어/문장 맞추기 게임 (`WordGame.java`, `Test_Game.java`)
* **요구사항 (`wordgame.txt`)**: 5글자의 영단어 또는 문장을 맞추는 게임으로, 다양한 난이도 모드를 제공함.
* **구현 핵심**: 
  * [cite_start]**4가지 모드**: 완전 랜덤 알파벳 생성, 사용자 직접 단어 설정, 미리 정의된 단어셋 활용, 문장(Sentence) 맞추기 모드를 구현함[cite: 1].
  * [cite_start]**상태 관리**: 정답 배열(`word`)과 가려진 배열(`secretWord`)을 비교하여 모든 문자를 맞췄는지(`end()` 메소드) 판단함[cite: 1].
  * [cite_start]**입력 검증**: 사용자가 입력한 문자가 알파벳인지 확인하고 대문자를 소문자로 자동 변환함[cite: 1, 3].

### 3. 회원 정보 관리 프로그램 (`Member.java`, `Storage.java`, `Test_Member.java`)
* **요구사항 (`MemberQ.txt`)**: 이름, 전화번호, 성별, 주소를 포함한 회원 정보를 등록하고 조회하는 기능을 구현함.
* **구현 핵심**: 
  * [cite_start]**데이터 저장**: `Storage` 클래스에서 `Member` 객체 배열을 관리하며 빈 공간에 회원을 저장함[cite: 2].
  * [cite_start]**다양한 검색**: 이름, 번호, 성별, 주소 등 각 속성별로 회원을 검색하는 기능을 제공함[cite: 2].
  * **정보 가공**: 성별 데이터(`M`/`F`)를 "남자"/"여자"로 변환하여 출력하고, `toString()`을 오버라이딩하여 정보를 정규화함.
  * **정적 멤버**: `static int count`를 활용하여 생성된 총 회원 수를 관리함.

## 🚀 실행 및 테스트 방법
1. Eclipse 워크스페이스에서 `d0108` 패키지를 선택합니다.
2. 각 프로젝트의 메인 실행 파일(`Test_...`)을 실행합니다.
   * **계산기**: `Test_Calc.java`
   * [cite_start]**단어 게임**: `Test_Game.java` [cite: 3]
   * **회원 관리**: `Test_Member.java`
3. **콘솔 인터페이스 가이드**:
   * 각 프로그램의 인트로 메뉴에 따라 번호를 입력하여 기능을 선택합니다.
   * `Scanner`를 통한 사용자 입력값에 따라 실시간으로 객체의 상태가 변화하는 것을 확인합니다.

## 📝 실습 회고
* **비즈니스 로직의 분리**: UI(콘솔 출력)와 데이터 처리(연산 및 저장)를 서로 다른 클래스에 배치하여 코드의 가독성과 유지보수성을 높였습니다.
* **배열 관리 역량**: 객체 배열(`Member[]`)을 순회하며 검색하거나, 문자 배열(`char[]`)을 제어하며 게임 로직을 구성하는 등 자료구조 활용 능력을 익혔습니다.
* **사용자 경험 고려**: 잘못된 입력(숫자 범위 초과, 알파벳 외 문자 입력 등)에 대한 예외 처리를 통해 프로그램의 안정성을 확보했습니다.
