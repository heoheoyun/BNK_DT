# ☕ Java Object-Oriented Programming (OOP) 심화 실습
> **금융DT 아카데미 d0108 패키지 - 객체 협력 및 데이터 관리 실습**

본 실습은 **String API**의 정교한 활용부터 **클래스 간 협력(Calculator, Member-Storage-Test)**을 통한 시스템 설계까지, Java를 활용한 소프트웨어 하부 구조 설계 능력을 배양하는 것을 목적으로 합니다.

---

## 🛠️ 개발 환경 및 핵심 개념
* **IDE**: Eclipse IDE
* **핵심 기술 역량**: 
    * **메소드 오버로딩(Overloading)**: `WordGame` 클래스에서 매개변수 타입(`char[]`, `String`)에 따라 `setSecretWord` 및 `start` 메소드를 다르게 정의하여 유연성 확보
    * **접근 제어 및 캡슐화**: `Member` 클래스의 필드를 `private`으로 보호하고 Getter/Setter 및 `toString()` 오버라이딩을 통해 데이터 무결성 유지
    * **정적 멤버(Static)**: `Member.count` 변수를 활용하여 인스턴스 생성 시마다 전체 회원 수를 공유 및 관리
    * **참조 비교 vs 내용 비교**: `String` 클래스의 `==` 연산자(주소 비교)와 `equals()` 메소드(값 비교)의 차이점 실습

## 📂 주요 실습 프로젝트 (d0108)

### 1. Java String API 마스터링 (`EX_String.java`)
* **문자열 가공**: `trim()`으로 공백을 제거하고, `replace()`를 통해 특정 패턴을 치환하며, `split()`을 이용해 데이터를 배열로 분할하는 실습 수행
* **데이터 검증 및 비교**: `startsWith()`, `contains()`, `equalsIgnoreCase()`를 활용한 조건부 로직 구현
* **형식화 및 변환**: `String.format()`을 이용한 출력 포맷팅 및 `valueOf()`를 통한 기본 타입의 문자열 변환 익힘

### 2. 모듈화 기반 사칙연산 시스템 (`Calculator.java`, `Test_Calc.java`)
* **역할 분리**: 연산 로직(`Calculator`)과 사용자 인터페이스(`Test_Calc`)를 분리하여 설계
* **방어적 프로그래밍**: 나누기(`div`) 연산 시 우항이 `0`인 경우를 사전에 체크하여 실행 에러 방지 로직 적용
* **정밀도 제어**: 정수 나눗셈 시 한쪽 항을 `double`로 명시적 형변환하여 소수점 결과값 확보

### 3. 단어/문장 추론 게임 알고리즘 (`WordGame.java`, `Test_Game.java`)
* **다양한 게임 모드**: 
    * **Mode 1/3**: `Random` 클래스를 활용한 알파벳 및 단어셋 기반 랜덤 추출
    * **Mode 2**: 사용자 정의 단어 설정 (대문자 자동 소문자 변환 로직 포함)
    * **Mode 4**: 공백이 포함된 문장(`Sentence`) 맞추기 모드 확장
* **상태 관리**: 정답 배열(`word`)과 사용자에게 보여줄 가려진 배열(`secretWord`, '*' 표시)을 별도로 관리하여 맞춘 글자만 실시간 업데이트

### 4. 객체 배열 기반 회원 관리 시스템 (`Member.java`, `Storage.java`, `Test_Member.java`)
* **CRUD 데이터 저장소**: `Storage` 클래스 내에 `Member[]` 객체 배열을 생성하고, 순회 문을 통해 빈 공간(`null`)을 찾아 회원을 등록하는 저장 로직 구현
* **다중 조건 검색**: 이름, 전화번호, 성별, 주소 등 속성별로 배열을 필터링하여 일치하는 정보만 출력하는 `search` 기능 구현
* **비즈니스 로직 적용**: 성별 코드(`M`/`F`)를 내부 로직을 통해 "남자"/"여자" 문자열로 변환하여 사용자에게 제공

* **객체 간의 협력**: 하나의 기능을 수행하기 위해 여러 클래스가 메시지(메소드 호출)를 주고받는 구조를 이해함.
