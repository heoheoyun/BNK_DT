## 📂 주요 실습 프로젝트 (d0108)

### 1. Java String 클래스 활용 (`EX_String.java`)
* **핵심 내용**: 문자열 데이터를 효율적으로 처리하기 위한 표준 메소드 실습
* **주요 기능**:
  * `length()`: 문자열의 전체 길이 반환
  * `charAt(index)`: 특정 위치의 문자 추출
  * `substring()`: 시작/종료 인덱스를 기준으로 문자열 일부 추출
  * `indexOf()` / `lastIndexOf()`: 특정 문자(열)의 위치 검색
  * `trim()`: 문자열 앞뒤의 공백 제거
  * `toUpperCase()` / `toLowerCase()`: 대소문자 변환
  * `replace()`: 특정 문자를 다른 문자로 치환

### 2. 사칙연산 계산기 시스템 (`Calculator.java`, `Test_Calc.java`)
* **요구사항**: 실행 클래스(UI)와 계산 로직 클래스의 명확한 분리
* **구현 핵심**: 
  * `Calculator` 클래스에서 사칙연산 메소드 구현
  * 나누기 연산 시 `double` 형변환을 통한 소수점 결과 도출 및 0으로 나누기 예외 처리

### 3. 영단어/문장 맞추기 게임 (`WordGame.java`, `Test_Game.java`)
* [cite_start]**요구사항**: 5글자 단어 또는 랜덤 문장 맞추기 게임 구현 [cite: 2]
* **구현 핵심**: 
  * [cite_start]**4가지 모드**: 완전 랜덤, 직접 단어 설정, 준비된 단어셋, 문장(Sentence) 맞추기 모드 제공 [cite: 1]
  * [cite_start]**로직 구현**: 정답 배열(`word`)과 가려진 배열(`secretWord`)을 비교하여 게임 진행 상태 관리 [cite: 1]
  * [cite_start]**검증**: `checkAlphabet()`을 통한 입력값 유효성 검사 및 대문자의 소문자 자동 변환 [cite: 1, 3]

### 4. 회원 정보 관리 프로그램 (`Member.java`, `Storage.java`, `Test_Member.java`)
* **요구사항**: 회원 정보 등록, 검색, 조회 기능을 포함한 데이터 관리 프로그램
* **구현 핵심**: 
  * [cite_start]**데이터 저장**: `Storage` 클래스에서 `Member` 객체 배열을 관리하며 순차적 저장 로직 구현 [cite: 2]
  * [cite_start]**다양한 검색**: 이름, 전화번호, 성별, 주소 등 각 필드별 맞춤 검색 기능 제공 [cite: 2]
  * **상태 관리**: `static int count`를 활용하여 등록된 회원 수 자동 카운팅
  * **정보 출력**: `toString()` 오버라이딩을 통한 객체 정보 출력 규격화
