# 🛠️ 핵심 기술 역량

## 예외 처리 메커니즘(Exception Handling)
- `try-catch` 블록을 통한 런타임 에러 제어 및 프로그램 안정성 확보
- 사용자 정의 예외(`My_Exception`)를 생성하여 비즈니스 로직에 특화된 예외 처리 구현
- `throws` 키워드로 메소드 간 예외 전파 및 책임 전가
- `printStackTrace()`를 활용한 디버깅 정보 추적

## 다형성 기반 범용 자료구조 설계
- `Object` 클래스를 활용한 무한 확장 배열(`InfinityObjectArray`) 구현
- `instanceof` 연산자로 런타임 타입 체크 후 안전한 다운캐스팅 수행
- 추상 클래스(`Parents`)를 통한 공통 인터페이스 정의 및 다형성 활용

## 전략 패턴(Strategy Pattern) 구현
- `PlayerLevel` 추상 클래스를 통한 행위의 캡슐화 및 동적 교체
- 런타임에 플레이어 레벨(`BeginnerLevel`, `AdvanceLevel`, `SuperLevel`)을 변경하여 동작을 전환
- `final` 메소드로 템플릿 메소드 패턴 적용: `go()` 메소드에서 `run()`, `jump()`, `turn()`의 실행 순서 고정

## 객체지향 설계 원칙 적용
- **캡슐화**: `private` 필드와 `public` 메소드를 통한 데이터 은닉 및 접근 제어
- **상속**: 추상 클래스를 상속받아 각 레벨별 고유 동작 구현
- **추상화**: `abstract` 메소드로 하위 클래스가 반드시 구현해야 할 계약 정의
- **다형성**: 상위 타입 참조로 하위 타입 객체를 다루어 유연한 코드 작성

## 동적 배열 관리 및 CRUD 구현
- 배열 용량 초과 시 자동으로 크기를 확장하는 `expand` 로직 구현
- 인덱스 기반 데이터 추가(`add`), 수정(`modify`), 조회(`showArray`) 기능
- 비즈니스 규칙 검증(과목명, 점수 범위 체크)을 통한 데이터 무결성 보장

# 📂 주요 실습 프로젝트 (d0114)

## 1. 예외 처리 시스템
- **기본 예외 처리**: `ArithmeticException`(0으로 나누기)과 `ArrayIndexOutOfBoundsException`을 하나의 `catch` 블록에서 처리
- **사용자 정의 예외**: `My_Exception` 클래스를 생성하여 `NullPointerException`을 포착 후 커스텀 예외로 재전송(`throw`)
- **예외 전파**: `f2()`에서 발생한 예외를 `f1()`이 포착하고, 다시 `main()`으로 전파하여 최종 처리하는 다단계 예외 처리 구조 구현

## 2. 성적 처리 프로그램 (`GradeProcessingProgram.java`)
- **데이터 모델링**: `Student`와 `Subject` 클래스로 학생과 과목 정보를 객체화
- **동적 학생 관리**: 초기 배열 크기 5에서 시작하여 학생 추가 시 자동으로 5씩 확장
- **비즈니스 로직**:
  - **과목 등록**: 학생별 최대 3개 과목(국어, 영어, 수학)을 배열로 관리
  - **성적 입력**: 학생 이름과 과목명으로 검색 후 점수(0~100) 설정
  - **성적표 출력**: 개별 학생의 총점, 평균을 계산하여 성적표 형식으로 출력
  - **일괄 조회**: 등록된 모든 학생의 성적표를 순차적으로 출력
- **데이터 검증**: 
  - 과목명은 "국어", "영어", "수학"만 허용
  - 점수는 0~100 범위 내에서만 입력 가능

## 3. 무한 확장 Object 배열 (`InfinityObjectArray.java`)
- **범용 컨테이너**: `Object[]` 배열로 모든 타입의 객체 저장 가능
- **자동 확장**: 배열이 가득 차면 3칸씩 자동 확장하여 무한 추가 지원
- **다형성 활용**: `Parents` 추상 클래스를 상속받은 객체(`A`, `B`, `C`)의 `f()` 메소드를 런타임에 동적으로 호출
- **타입 안전성**: `instanceof`로 타입을 확인한 후 캐스팅하여 `ClassCastException` 방지
- **실습 내용**: 
  - 문자열, 숫자, 커스텀 객체를 혼합하여 배열에 저장
  - 특정 인덱스의 객체를 수정하고 전체 배열 출력
  - `Parents` 타입 객체만 필터링하여 각자의 고유 메소드 실행

## 4. 플레이어 레벨 시스템 (전략 패턴 실습)
- **추상 클래스 설계**: `PlayerLevel`에 `run()`, `jump()`, `turn()`, `showLevelMessage()` 추상 메소드 정의
- **템플릿 메소드**: `final void go(int count)` 메소드로 실행 순서를 고정하고, 각 레벨별 구현은 추상 메소드에 위임
- **레벨별 구현**:
  - `BeginnerLevel`: 천천히 달리기, 점프 불가, 턴 불가
  - `AdvanceLevel`: 빨리 달리기, 높이 점프, 턴 불가
  - `SuperLevel`: 엄청 빨리 달리기, 아주 높이 점프, 한 바퀴 턴
- **동적 레벨 변경**: `Player` 클래스의 `upgradeLevel()` 메소드로 런타임에 플레이어 능력을 전환
- **전략 패턴의 이점**: 새로운 레벨(예: `ExpertLevel`)을 추가해도 `Player` 클래스는 수정할 필요 없이 확장 가능

# 📝 실습 회고

## 예외 처리의 중요성
예외를 적절히 처리하지 않으면 프로그램이 비정상 종료되는 것을 직접 경험하며, `try-catch`와 사용자 정의 예외를 통해 안정적인 프로그램 흐름을 설계하는 방법을 체득함

## 다형성의 실용성
`Object` 타입 배열과 추상 클래스를 결합하여 서로 다른 타입의 객체를 하나의 자료구조로 관리하는 유연함을 경험. `instanceof`와 캐스팅을 통한 타입별 처리 방식이 실무에서 어떻게 활용될 수 있는지 이해함

## 전략 패턴을 통한 유연한 설계
플레이어 레벨 시스템을 구현하면서 전략 패턴의 핵심 개념을 체득함. 행위를 객체로 캡슐화하고 런타임에 교체할 수 있는 구조가 게임, UI 상태 관리 등 실무에서 얼마나 유용한지 경험함. `final` 키워드로 템플릿 메소드를 보호하여 일관된 실행 흐름을 보장하는 방법도 학습함

## 배열 기반 자료구조의 한계와 해결
배열의 고정 크기 한계를 동적 확장 로직으로 해결하면서, 이후 학습할 `ArrayList` 같은 컬렉션 프레임워크의 내부 동작 원리를 미리 체감함. 인덱스 관리와 null 체크의 중요성을 다시 한번 확인함

## 객체지향 설계 실습
성적 처리 프로그램을 통해 실제 업무에서 마주할 수 있는 요구사항(학생 관리, 성적 계산)을 객체지향적으로 모델링하고, 각 클래스의 책임을 분리하여 유지보수성 높은 코드를 작성하는 연습을 함. 추상 클래스와 상속을 활용한 코드 재사용의 효과를 체감함
