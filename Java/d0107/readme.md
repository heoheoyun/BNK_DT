# ☕ Java Object-Oriented Programming (OOP) 심화 실습
> **금융DT 아카데미 d0107 패키지 - 객체 간 상호작용 및 설계 학습**

이 폴더는 요구사항 정의서(Quest)를 분석하고, 이를 Java의 객체지향 원칙을 적용하여 코드로 구현한 심화 실습 결과물들을 담고 있습니다.

---

## 🛠️ 개발 환경 및 핵심 개념
* **IDE**: Eclipse IDE
* **핵심 개념**: 
  * **캡슐화(Encapsulation)**: `private` 필드와 Getter/Setter를 통한 데이터 보호
  * **상호작용(Interaction)**: 객체가 다른 객체의 메소드를 호출하여 협력하는 구조
  * **정적 멤버(Static)**: 인스턴스 간 공유 데이터 처리

---

## 📂 주요 실습 프로젝트 (d0107)

### 1. 버스 승차 시스템 (`Bus.java`, `PStudent.java`, `Test_Bus.java`)
* **요구사항 (`BusQ.txt`)**: 학생은 요금을 지불하고 버스에 탑승하며, 버스는 승객 수와 수입을 관리함.
* **구현 핵심**: `PStudent` 객체가 `Bus` 객체를 매개변수로 받아 `bus.boarding()`을 호출하는 객체 간 협력 로직 구현.

### 2. 유닛 전투 시뮬레이션 (`Unit.java`, `Test_Unit.java`)
* **요구사항 (`UnitQ.txt`)**: 유닛은 공격 능력을 가지며, 공격받은 유닛은 에너지가 감소하고 에너지가 0이 되면 동작을 정지함.
* **구현 핵심**: 객체의 상태(`energy`, `is_Alive`)에 따른 조건부 행위 처리 및 유닛 파괴 시 예외 로직 구현.

### 3. 수명 관리 프로그램 (`Human.java`, `Test_Human.java`)
* **요구사항 (`HumanQ.txt`)**: 특정 행위(흡연, 음주)가 객체의 속성(수명)에 영향을 주는 시뮬레이션.
* **구현 핵심**: `private` 접근 제한자를 통한 정보 은닉과 메소드를 통한 간접적인 상태 변경 제어.

### 4. 클래스 및 메모리 구조 학습
* **`Student.java` / `Ex_Instance02.java`**: 생성자 오버로딩과 `static` 변수를 이용한 전체 학생 수 카운팅 로직.
* **`Ex_Char.java`**: `char` 타입의 내부 유니코드 동작 방식 및 문자 데이터 처리.
* **`Test_Instance.java`**: 인스턴스 변수와 스태틱 변수의 메모리 적재 차이 분석.

## 🚀 실행 및 테스트 방법
1. Eclipse 워크스페이스에서 `d0107` 패키지를 탐색합니다.
2. 각 예제의 실행 파일인 `Test_...` 혹은 `Ex_...` 파일에서 `Right Click` > `Run As` > `Java Application` (또는 `Ctrl + F11`)을 실행합니다.
3. 콘솔 창을 통해 객체 간 상호작용 결과(메시지 출력 및 데이터 변화)를 확인합니다.

---

## 📝 실습 회고
* **객체 중심 설계**: 기능별로 코드를 나열하는 방식에서 벗어나, 현실 세계의 사물을 객체로 정의하고 그들 사이의 관계를 설정하는 '객체지향적 사고'를 확립함.
* **데이터 무결성**: Setter 메소드 내에 조건문을 추가하여 수명이 음수가 되거나 잔액 부족 시 승차가 거부되는 등의 예외 상황을 처리하며 데이터의 무결성을 보장하는 법을 익힘.
