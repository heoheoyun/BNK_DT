> **금융DT 아카데미 개발자 양성과정 - Eclipse 실습 프로젝트**

이 저장소는 Java의 핵심 알고리즘(정렬, 탐색)과 클래스/객체를 활용한 데이터 관리 기초를 학습한 기록입니다. 특히 로또 번호 생성기, 사칙연산 계산기 등 실전 예제를 통해 로직 설계 능력을 배양하였습니다.

* **IDE**: Eclipse IDE

## 📂 주요 실습 및 알고리즘 요약

### 1. 알고리즘 및 배열 관리 (`Ex_NumQ.java`, `Ex_array05.java`)
* **이진 탐색(Binary Search)**: 정렬된 배열에서 중간값을 기준으로 탐색 범위를 좁혀나가는 효율적인 탐색 알고리즘 구현
* **버블 정렬(Bubble Sort)**: 인접한 원소 간의 비교와 위치 교환(Swap)을 통해 난수를 오름차순으로 정렬

### 2. 실전 응용 프로그램 (`Ex_array04.java`, `Test.java`)
* **로또 번호 생성기**: `Random` 클래스를 활용해 1~45 사이의 중복 없는 난수를 생성하고, 사용자 입력 값과 비교하여 당첨 등수 산출
* **기능형 계산기**: 메소드(`Calc`, `Result`)를 분리하여 사칙연산, 몫, 나머지, 제곱 기능을 구현하고 연산 횟수를 통계로 출력

### 3. 객체지향 프로그래밍 기초 (`Student.java`, `Test_Student.java`)
* **클래스 설계**: 학생의 번호, 이름, 성별 데이터를 가지는 `Student` 클래스 정의
* **객체 배열**: 생성된 여러 개의 객체를 배열(`Student[]`)에 저장하고 `for`문을 통해 일괄 관리 및 성별 통계 산출
* **메소드 활용**: 객체 내부에 `showStudentInfo()` 메소드를 정의하여 데이터 출력 로직을 캡슐화
