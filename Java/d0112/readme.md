# ☕ Java 객체지향 프로그래밍(OOP) 핵심: 상속, 다형성 및 인터페이스
> **금융DT 아카데미 d0112 패키지 - 객체지향 모델링 및 급여 관리 시스템 실습**

본 실습은 **상속(Inheritance)**을 통한 코드 재사용, **추상화(Abstraction)**를 이용한 규격 정의, 그리고 **다형성(Polymorphism)**을 활용한 유연한 시스템 설계를 학습하는 것을 목표로 합니다. 특히, 정규직과 비정규직의 급여 체계를 모델링하며 실무적인 객체지향 설계 능력을 배양하였습니다.

---

## 🛠️ 핵심 기술 역량
* **추상화 및 상속**: 공통 속성(이름, 사번)을 부모 클래스(`Employee`)에 정의하고, 구체적인 특성은 자식 클래스(`Regular`, `Nonregular`)에서 확장
* **메소드 오버라이딩**: 급여 계산(`setSalary`) 및 사번 부여(`setNo`) 로직을 각 고용 형태에 맞게 재정의
* **다형성(Polymorphism)**: 부모 타입(`Employee`)의 참조 변수로 서로 다른 자식 객체들을 일괄 관리하고, `Company` 클래스에서 동일한 인터페이스(`showEmployeeInfo`)로 정보 출력
* **인터페이스 구현**: 상속 계층이 다른 객체들에게 `Flyable`, `Swimable`과 같은 공통 행위 규약 적용

---

## 📂 주요 실습 프로젝트 (d0112)

### 1. 급여 관리 시스템 모델링 (`Regular.java`, `Nonregular.java`, `Test_Salaries.java`)
* **비즈니스 로직 구현**: 
    * **정규직**: 기본급 + 보너스(10%) 체계 및 'j'로 시작하는 사번 체계 구현
    * **비정규직**: 시급 × 근무시간 체계 및 'b'로 시작하는 사번 체계 구현
* **시스템 확장성**: `Employee`라는 부모 타입을 활용하여 `Company` 클래스에서 어떤 형태의 직원 객체가 들어오더라도 수정 없이 정보를 출력할 수 있는 유연함 확보



### 2. 추상 클래스 기반 교통 시스템 (`Transportation.java`, `Bus.java`, `Train.java`)
* **규격 강제**: `abstract` 메소드 `go()`를 통해 모든 교통수단이 반드시 이동 로직을 구현하도록 강제
* **의존성 분리**: `BusanTravel`은 구체적인 운송 수단이 아닌 추상화된 `Transportation`에 의존하여 결합도를 낮춤

### 3. 인터페이스 다중 구현 (`Flyable.java`, `Swimable.java`, `Person.java`)
* **기능적 확장**: `Person` 클래스가 `God`을 상속받는 동시에 여러 인터페이스를 `implements` 하여 다양한 행위를 수행하는 구조 실습
* **공통 그룹화**: 상속 관계가 없는 `Bird`, `Car`, `Person`을 `Flyable`이라는 인터페이스로 묶어 다형성 적용

### 4. 객체 계층 및 생성자 원리 (`MouseTest.java`, `Test.java`)
* **super() 활용**: 자식 객체 생성 시 부모 생성자를 호출하여 필드를 초기화하는 객체 생성 메커니즘 이해
* **타입 확인**: `instanceof` 연산자를 사용하여 런타임에 객체의 실제 타입을 판별하고 안전하게 다운캐스팅 수행

## 📝 실습 회고
* **객체지향 설계의 이점**: 직원 급여 시스템 실습을 통해, 부모 클래스에서 규격을 정하고 자식에서 세부를 구현하는 방식이 코드 유지보수에 얼마나 효율적인지 체감함.
* **유연한 코드 작성**: 다형성을 활용하면 새로운 직원 유형(예: 계약직)이 추가되더라도 기존의 `Company`나 출력 로직을 변경할 필요가 없다는 점(OCP 원칙)이 가장 큰 수확임.
* **실무적 적용**: 단순한 문법 공부를 넘어, 실제 요구사항(`SalariesQ.txt`)을 클래스 다이어그램으로 옮기고 코드로 구현해보며 모델링 역량을 강화함.
