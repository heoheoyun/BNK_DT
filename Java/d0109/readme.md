# ☕ Java 자료구조 및 객체 상호작용 실습
> **금융DT 아카데미 d0109 패키지 - 동적 배열 구현 및 자판기 시스템 설계**

본 실습은 배열의 물리적 한계를 극복하는 **가변 배열(InfinityArray)**의 로직을 직접 구현하고, **자판기-제품-이용객** 간의 유기적인 객체 협력을 통해 실전 프로그래밍 감각을 익히는 것을 목적으로 합니다.

---

## 🛠️ 개발 환경 및 핵심 개념
* **IDE**: Eclipse IDE
* **핵심 기술 역량**: 
    * **동적 배열(Dynamic Array) 원리**: 고정된 크기의 배열이 가득 찼을 때, 더 큰 새로운 배열을 생성하고 기존 데이터를 복사(`System.arraycopy` 원리)하여 크기를 확장하는 로직 구현
    * **객체 간 협력(Object Collaboration)**: `VendingMachine`이 `Products`를 관리하고, `User`가 `VendingMachine`과 상호작용하며 데이터를 주고받는 설계
    * **생성자 체이닝(Constructor Chaining)**: `Member` 클래스에서 `this()`를 사용하여 필수 필드와 선택적 필드를 처리하는 생성자 효율화
    * **유효성 검증(Validation)**: 로그인 시 ID/PW 길이 제한 및 데이터 일치 여부를 확인하는 방어적 로직 적용

## 📂 주요 실습 프로젝트 (d0109)

### 1. 가변 길이 배열 구현 (`InfinityArray.java`, `Test_InfinityArray.java`)
* **자동 확장 로직**: `insert()` 시 공간이 부족하면 `add()` 메소드를 호출하여 기존 배열보다 지정된 `increase` 값만큼 큰 새로운 배열로 데이터를 이주(Migration)시킴
* **데이터 관리 기능**:
    * **modify**: 유효한 인덱스 범위를 체크하여 데이터 수정
    * **delete**: 특정 인덱스의 데이터를 삭제하고 뒤의 데이터를 앞으로 당겨 빈 공간을 메우는 알고리즘 구현
* **추상화**: 배열의 물리적 크기(`length`)와 실제 데이터가 차 있는 크기(`not_fill_idx`)를 분리하여 관리



### 2. 자판기 시뮬레이션 시스템 (`VendingMachine.java`, `Products.java`, `User.java`, `Test_VM.java`)
* **객체 지향 설계**:
    * **Products**: 이름, 수량, 가격 정보를 가지며 품절 상태(`isSoldout`)를 스스로 판단
    * **VendingMachine**: `Products` 객체 배열을 관리하며 제품 등록, 판매 처리, 거스름돈 계산 로직 담당
    * **User**: 보유 금액과 소지품(`goods[]`)을 관리하며 자판기를 통해 물건을 구매하는 주체
* **상호작용 로직**: 구매 시 사용자의 잔액 확인 -> 자판기의 재고 확인 -> 판매 승인 및 거스름돈 반환의 프로세스를 코드로 구현

### 3. 로그인 및 회원가입 시스템 (`Member.java`, `Test_Member.java`)
* **회원가입 규정**: ID(4글자 이상), Password(8글자 이상)의 최소 길이를 검증하여 조건 미달 시 재입력을 요구하는 `while` 루프 구현
* **로그인 처리**: 생성된 `Member` 객체의 `check()` 메소드를 통해 입력값과 저장된 데이터의 일치 여부를 판단하고, 로그인 성공 시 사용자 이름을 포함한 환영 메시지 출력
* **데이터 포맷팅**: `toString()` 오버라이딩을 통해 객체의 정보를 정돈된 형태의 문자열로 반환

* **사용자 경험 고려**: 잘못된 입력에 대한 피드백 메시지 제공 및 재입력 유도 로직을 통해 프로그램의 완성도를 높임.
