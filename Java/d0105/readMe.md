# ☕ Java 기초 프로그래밍 학습 기록
> **금융DT 아카데미 개발자 양성과정 - Eclipse 활용 실습**

이 저장소는 **Eclipse IDE**를 사용하여 Java의 기본 문법과 알고리즘 기초를 학습한 소스 코드를 담고 있습니다. C언어에서 배운 로직을 Java로 옮겨보거나, Java 특유의 객체 및 라이브러리 활용법을 익히는 데 집중했습니다.

---

## 🛠️ 개발 환경
* **IDE**: Eclipse IDE
* **Language**: Java 8 / 11 / 17 (JDK)
* **Library**: `java.util.Scanner`, `java.util.Random`

---

## 📂 주요 학습 내용 및 예제

### 1. 기본 제어문 (`Ex_for.java`, `Test.java`, `Test02.java`)
* **반복문 활용**: `for`와 `while`문을 이용한 구구단 출력 및 별 찍기 패턴 구현
* **조건문 분기**: `if-else` 및 `switch-case`를 활용한 가위바위보 게임 로직 구현
* **무한 루프와 탈출**: `while(true)`와 `break`를 이용한 흐름 제어

### 2. 배열 활용 및 알고리즘 (`Ex_array01.java` ~ `Ex_array03.java`)
* **1차원 배열**: 배열 요소의 병합, 총합 계산 및 출력 형식 제어 (쉼표 처리)
* **2차원 배열**: 행과 열을 이용한 데이터 접근 및 중첩 반복문 활용
* **응용 알고리즘**:
  * **Snake 형식 배열 채우기**: `boolean flag`를 활용한 지그재그 데이터 입력
  * **확률 시뮬레이션**: `Random` 클래스를 이용한 주사위 빈도수 계산

---

## 🚀 Eclipse 실습 방법
1. **Import**: `File` > `Open Projects from File System`을 통해 해당 폴더를 워크스페이스에 추가합니다.
2. **Run**: 각 `.java` 파일에서 `Ctrl + F11`을 눌러 결과를 확인합니다.
3. **Console**: 이클립스 하단 콘솔 탭에서 `Scanner` 입력을 수행하거나 출력 결과를 확인합니다.

## 📝 학습 포인트
* **C vs Java**: C언어로 구현했던 로직(가위바위보 등)을 Java의 `Scanner`와 `Random` 클래스를 사용하여 새롭게 구현해 봄.
* **데이터 구조**: 2차원 배열을 활용하여 복잡한 데이터 저장 방식을 연습함.
* **출력 가독성**: `printf` 및 조건문을 활용하여 사용자에게 보여지는 출력 포맷을 정교화함.
