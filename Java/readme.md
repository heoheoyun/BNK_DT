# ☕ Java Programming 학습 저장소
> **금융DT 아카데미 개발자 양성과정 - Java 기초 실습 공간**

이 저장소는 **Eclipse IDE**를 활용하여 Java 프로그래밍의 기초를 학습하고 실습한 코드들을 관리하는 공간입니다.

---

## 🛠️ 개발 환경 (Environment)
* **IDE**: Eclipse IDE (Enterprise Edition)
* **JDK**: Java SE (JDK 17)
* **Build**: Eclipse Built-in Builder

---

## 📂 프로젝트 구조
* 각 폴더는 Eclipse의 **Java Project** 또는 **Package** 단위로 구성되어 있습니다.
* 소스 파일(`.java`)은 각 프로젝트 내의 `src` 폴더에서 확인할 수 있습니다.

---

## 🚀 Eclipse에서 실행 및 확인 방법

1. **프로젝트 가져오기 (Import)**:
   * `File` -> `Import...` -> `General` -> `Existing Projects into Workspace` 선택
2. **코드 실행**:
   * 실행하려는 파일 선택 후 상단 **Run 아이콘(▶️)** 클릭
   * 또는 단축키 `Ctrl + F11` 사용
3. **결과 확인**:
   * 하단 **Console** 탭을 통해 출력 결과 확인

---

## 📝 학습 기록 가이드
* 모든 소스 코드는 Eclipse 표준 코딩 컨벤션을 준수하며 작성되었습니다.
* Java의 객체지향적 특징을 이해하고 구현하는 데 집중하였습니다.
