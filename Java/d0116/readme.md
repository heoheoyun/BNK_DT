# 🛠️ 핵심 기술 역량

## Map 자료구조 활용 (HashMap)
- Key-Value 쌍으로 데이터를 저장하는 `HashMap<K, V>` 구조 이해 및 활용
- 주요 메소드: `put()`, `get()`, `getOrDefault()`, `containsKey()`, `keySet()`, `size()`, `isEmpty()`, `clear()`
- 중복 Key 처리: 동일한 Key로 `put()` 시 기존 Value를 덮어씀
- `keySet()`을 통한 Key 집합 추출 및 반복문으로 전체 데이터 순회

## Set 자료구조 활용 (HashSet)
- 중복을 허용하지 않는 `HashSet<E>` 구조의 특성 이해
- 주요 메소드: `add()`, `remove()`, `contains()`, `size()`
- 중복 요소 추가 시 자동으로 무시되는 특성 확인
- 순서가 보장되지 않는 비순차 컬렉션의 특징 체득

## Arrays 유틸리티 클래스 활용
- **배열 복사**: `Arrays.copyOf()`, `Arrays.copyOfRange()`, 커스텀 `arrayCopy()` 구현
- **배열 정렬**: `Arrays.sort()`를 통한 기본 타입 및 객체 배열 정렬
- **배열 비교**: `Arrays.equals()`로 배열 요소를 하나씩 비교하여 동등성 판단
- 제네릭 메소드를 활용한 범용 배열 유틸리티 함수 구현

## Comparable 인터페이스와 객체 정렬
- `Comparable<T>` 인터페이스 구현으로 객체의 자연 순서(Natural Order) 정의
- `compareTo(T o)` 메소드 재정의를 통한 사용자 정의 정렬 기준 설정
  - 양수 반환: 현재 객체가 더 큼
  - 음수 반환: 현재 객체가 더 작음
  - 0 반환: 두 객체가 같음
- `Arrays.sort()`와 결합하여 객체 배열을 자동 정렬

## 정렬 알고리즘 구현
- **선택 정렬(Selection Sort)** 알고리즘 직접 구현
- 최소값을 찾아 앞쪽부터 교환하는 방식으로 배열 정렬
- 시간 복잡도 O(n²)의 기본 정렬 알고리즘 이해

## 실전 프로젝트: 한영 사전 시스템
- `HashMap`을 활용한 단어-의미 저장 및 퀴즈 정답 횟수 기록
- CRUD 기능: 단어 등록, 전체/선택 조회, 랜덤 퀴즈 출력
- 사용자 입력 처리 및 검증 로직 구현
- 알파벳 순 정렬을 위한 `Arrays.sort()` 활용

# 📂 주요 실습 프로젝트 (d0116)

## 1. HashMap 기본 실습 (`ExMap.java`)
- **데이터 추가**: `put(key, value)`로 과일 이름과 가격 저장
- **데이터 조회**: `get(key)`로 특정 Key의 Value 반환, `getOrDefault(key, defaultValue)`로 Key 미존재 시 기본값 반환
- **중복 Key 처리**: "포도" Key로 4000과 3000을 연속 저장 시 마지막 값(3000)만 유지됨을 확인
- **전체 순회**: `keySet()`으로 모든 Key를 추출하고 향상된 for문으로 Key-Value 쌍 출력
- **맵 관리**: `size()`, `isEmpty()`, `clear()` 메소드로 맵 상태 확인 및 초기화

## 2. HashSet 기본 실습 (`ExSetTest.java`)
- **요소 추가**: `add()`로 과일 이름 저장
- **중복 확인**: "사과"를 두 번 추가해도 Set에는 하나만 저장됨
- **요소 검색**: `contains()`로 특정 요소 존재 여부 확인
- **요소 삭제**: `remove()`로 특정 요소 제거 후 크기 감소 확인
- **순서 미보장**: Set의 출력 순서가 입력 순서와 다를 수 있음을 확인

## 3. Arrays 유틸리티 실습 (`CopyArrayTest.java`)
- **전체 복사**: `Arrays.copyOf(original, length)`로 배열 전체를 새 배열로 복사
- **부분 복사**: `Arrays.copyOf(original, 3)`으로 처음 3개 요소만 복사
- **범위 복사**: `Arrays.copyOfRange(original, 2, 4)`로 인덱스 2~3 요소 복사
- **커스텀 복사**: `MySystem.arrayCopy()`를 제네릭 메소드로 구현하여 System.arraycopy() 모방

## 4. 객체 정렬 실습 (`PersonSortTest.java`)
- **Comparable 구현**: `Person` 클래스에서 `compareTo()` 메소드를 재정의하여 나이 또는 이름 기준 정렬
- **이름 기준 정렬**: `String.compareTo()`를 활용하여 이름의 사전 순으로 정렬
- **Arrays.sort() 활용**: `Person[]` 배열을 `Arrays.sort()`로 자동 정렬
- **실행 결과**: Choi(15), Han(35), Lee(20) 순으로 이름 사전 순 정렬됨

## 5. 선택 정렬 구현 (`SelectionSort.java`)
- **알고리즘 로직**:
  1. 배열에서 최소값의 인덱스를 찾음
  2. 최소값을 현재 위치와 교환
  3. 다음 위치로 이동하여 반복
- **최적화**: 현재 값과 최소값이 같으면 교환 생략
- **비교**: `Arrays.sort()`의 내부 정렬 알고리즘과 성능 차이 체감

## 6. 한영 사전 프로그램 (`Dictionary.java`)
- **데이터 구조**:
  - `HashMap<String, String> words`: 영어 단어-한글 뜻 저장
  - `HashMap<String, Integer> record`: 단어별 퀴즈 정답 횟수 기록
- **핵심 기능**:
  - **등록(`add()`)**: 영어 단어와 한글 뜻을 입력받아 Map에 저장, 단어는 소문자로 변환 후 저장
  - **전체 조회(`getAll()`)**: 등록된 모든 단어를 알파벳 순으로 정렬 후 출력
  - **선택 조회(`getBy()`)**: 특정 단어의 뜻과 퀴즈 정답 횟수 출력
  - **퀴즈(`quiz()`)**: 랜덤으로 단어를 선택하여 뜻을 맞추는 퀴즈 진행, 정답 시 기록 증가
- **알파벳 정렬**: `keySet()`을 배열로 변환 후 `Arrays.sort()`로 정렬하여 사전식 출력
- **사용자 인터페이스**: `Scanner`로 메뉴 선택 및 입력 처리, 반복문으로 지속적인 상호작용 제공

## 7. 배열 비교 실습 (`ArrayObjEquals.java`)
- **객체 배열 비교**: `equals()` 재정의 없이는 참조 비교만 수행
- **Arrays.equals() 활용**: `INum` 클래스에서 `equals()` 재정의 후 `Arrays.equals(ar1, ar2)`로 배열 요소 단위 비교
- **깊은 비교**: 각 인덱스의 객체를 `equals()`로 비교하여 논리적 동등성 판단

# 📝 실습 회고

## Map과 Set의 실용성
`HashMap`과 `HashSet`의 특성을 직접 활용하며 Key-Value 기반 데이터 관리와 중복 제거의 효율성을 체감함. 특히 한영 사전 프로젝트에서 단어 검색과 중복 방지를 자연스럽게 처리할 수 있었음

## 정렬의 원리와 활용
`Comparable` 인터페이스를 구현하고 `compareTo()` 메소드를 재정의하며 객체 정렬의 내부 메커니즘을 이해함. `Arrays.sort()`가 단순히 편리한 메소드가 아니라 객체의 비교 규칙을 기반으로 동작한다는 점을 깨달음

## 알고리즘 구현의 중요성
선택 정렬을 직접 구현하며 정렬 알고리즘의 기본 원리를 체득함. 라이브러리 메소드를 사용하는 것도 중요하지만, 내부 동작을 이해하면 성능 최적화와 문제 해결 능력이 향상됨을 경험함

## Arrays 유틸리티의 강력함
배열 복사, 정렬, 비교 등 반복적인 작업을 `Arrays` 클래스가 간결하게 처리해주는 것을 확인함. 직접 구현한 `arrayCopy()`와 비교하며 제네릭 메소드의 재사용성을 다시 한번 실감함

## 실전 프로젝트를 통한 통합 학습
한영 사전 프로그램을 구현하며 `HashMap`, `Arrays.sort()`, `Scanner`, 제어문, 메소드 분리 등 여러 개념을 통합적으로 활용함. 단순한 기능 학습을 넘어 실무에 가까운 프로그램을 설계하고 구현하는 경험을 쌓음

## 객체 비교의 정확성
`equals()`와 `Arrays.equals()`를 통해 참조 비교와 값 비교의 차이를 명확히 이해함. 객체 배열을 비교할 때는 반드시 `equals()`를 재정의해야 정확한 비교가 가능하다는 점을 체득함
