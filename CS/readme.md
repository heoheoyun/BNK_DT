금융DT 아카데미 개발자 양성과정 - C언어 입문 실습 저장소

이 저장소는 Dev-C++ 환경에서 C언어의 심화 문법을 실습하고, 메모리 구조와 데이터 설계 등 컴퓨터 과학(CS)의 핵심 원리를 학습한 기록을 담고 있습니다.

🛠️ 개발 환경 (Environment)
IDE: Dev-C++ 5.11 (TDM-GCC 4.9.2)

Compiler: MinGW GCC

Language: C (C99/C11)

📂 학습 커리큘럼
C 프로그래밍 기초
Dev-C++ 프로젝트 생성 및 설정

기본 입출력 함수: printf(), scanf()

자료형(int, float, char)과 변수 선언

제어문과 논리
if, else if, else 조건문

switch-case 분기 처리

🧠 메모리 관리와 데이터 설계 (Update)
포인터(Pointer): 메모리 주소의 개념 이해 및 직접 참조 (*, & 연산자)

함수(Function): 모듈화된 프로그래밍, 매개변수 전달(Call by Value / Call by Reference)

구조체(Structure): 사용자 정의 자료형을 통한 복합 데이터 관리

🚀 Dev-C++ 실행 및 컴파일 방법
소스 코드 작성: .c 확장자로 파일을 생성합니다.

컴파일 (Compile): 상단 메뉴의 Execute -> Compile (단축키 F9)을 누릅니다.

실행 (Run): 상단 메뉴의 Execute -> Run (단축키 F10)을 누릅니다.

Tip: F11을 누르면 컴파일과 실행을 동시에 할 수 있습니다.

📝 주요 학습 내용 (Review)
메모리 구조 이해: 포인터를 통해 컴퓨터의 실제 메모리에 어떻게 데이터가 저장되고 접근되는지 학습함.

함수와 재사용성: 기능을 독립적인 함수로 분리하여 코드의 가독성과 재사용성을 높임.

데이터 모델링: 구조체를 활용하여 금융 데이터(예: 계좌 정보, 고객 정보)와 같은 복잡한 데이터를 논리적으로 묶는 연습을 함.

CS 사고력: 하드웨어와 소프트웨어의 상호작용을 깊이 있게 이해하며 효율적인 알고리즘 설계의 토대를 마련함.
