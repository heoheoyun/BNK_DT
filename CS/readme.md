## 📂 학습 커리큘럼

### 1. C 프로그래밍 기초
* Dev-C++ 프로젝트 생성 및 설정
* 기본 입출력 함수: `printf()`, `scanf()`
* 자료형(int, float, char)과 변수 선언

### 2. 제어문과 논리
* `if`, `else if`, `else` 조건문
* `switch-case` 분기 처리
* 논리 연산자를 활용한 조건 설계

### 3. 메모리 및 데이터 구조 활용 (Key Topics)
* **포인터(Pointer)**: 메모리 주소 개념, 간접 참조 연산자(`*`, `&`) 활용
* **함수(Function)**: 함수의 정의와 호출, 매개변수 전달 방식(Call by Value/Reference)
* **구조체(Structure)**: 사용자 정의 자료형을 통한 복합 데이터 그룹화

## 🚀 Dev-C++ 실행 및 컴파일 방법

1. **소스 코드 작성**: `.c` 확장자로 파일을 생성합니다.
2. **컴파일 (Compile)**: 상단 메뉴의 `Execute` -> `Compile` (단축키 `F9`)을 누릅니다.
3. **실행 (Run)**: 상단 메뉴의 `Execute` -> `Run` (단축키 `F10`)을 누릅니다.
   * *Tip: `F11`을 누르면 컴파일과 실행을 동시에 할 수 있습니다.*

* **메모리 직접 제어**: 포인터를 학습하며 프로그램이 RAM 메모리를 어떻게 사용하는지 깊이 있게 이해함.

* **디버깅 기초**: 포인터 연산 시 발생하는 런타임 에러를 추적하며 프로그램의 실행 흐름을 파악함.
