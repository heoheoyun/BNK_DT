## 📂 학습 커리큘럼

### 1. C 프로그래밍 기초
* Dev-C++ 프로젝트 생성 및 설정
* 기본 입출력 함수: `printf()`, `scanf()`
* 자료형(int, float, char)의 크기와 변수 선언

### 2. 제어문과 논리
* `if`, `else if`, `else` 조건문
* `switch-case` 분기 처리
* 논리 연산자를 통한 프로그램 흐름 제어

### 3. CS 핵심: 메모리와 추상화 (Key Topics)
* **포인터(Pointer)**: 주소 연산자(`&`)와 참조 연산자(`*`)를 이용한 메모리 직접 접근 및 이해
* **함수(Function)**: 함수의 정의, 호출 스택(Stack)의 이해, 매개변수 전달 방식
* **구조체(Structure)**: 연관된 데이터를 하나로 묶어 새로운 타입을 만드는 데이터 추상화 실습

## 🚀 Dev-C++ 실행 및 컴파일 방법

1. **소스 코드 작성**: `.c` 확장자로 파일을 생성합니다.
2. **컴파일 (Compile)**: 상단 메뉴의 `Execute` -> `Compile` (단축키 `F9`)을 누릅니다.
3. **실행 (Run)**: 상단 메뉴의 `Execute` -> `Run` (단축키 `F10`)을 누릅니다.
   * *Tip: `F11`을 누르면 컴파일과 실행을 동시에 할 수 있습니다.*

## 📝 주요 학습 내용 (Review)



* **저수준 메모리 제어**: 포인터를 통해 변수가 메모리 상의 실제 주소에 어떻게 할당되고 접근되는지 학습함.
* **프로그램 모듈화**: 함수를 통해 복잡한 로직을 작은 단위로 분리하고 코드의 논리적 구조를 설계함.
* **복합 데이터 설계**: 구조체를 사용하여 서로 다른 타입의 데이터를 하나의 단위로 정의함으로써 소프트웨어 설계의 기초를 다짐.
* **컴퓨팅 사고(Computational Thinking)**: 문법을 넘어 컴퓨터가 데이터를 처리하는 물리적 방식과 논리적 흐름을 동시 이해함.
